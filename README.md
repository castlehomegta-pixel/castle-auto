# Castle Auto Demo

Static approval build for GitHub Pages / WHC preview.

## Edit inventory
Open `assets/js/cars.js`. Each vehicle has title, price, mileage, status, image and description in one place.

## Replace photos
Put new images in `assets/images/`, then change the `image` value in `cars.js`.

## Forms
Forms are demo-only right now. After approval they can be connected to GoHighLevel forms/webhooks.

## Deploy on GitHub Pages
Upload this entire folder to a GitHub repository and enable Pages from the repository settings.

## Production recommendation
After design approval, either keep this lightweight static build on WHC or reproduce the approved UI as a WordPress theme/template with an editable Vehicle content type. WordPress is preferable if the client will frequently manage inventory without touching code.
